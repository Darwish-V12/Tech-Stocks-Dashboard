# 📈 Tech Stocks Analysis Dashboard

An interactive and comprehensive data analysis dashboard designed to track, visualize, and analyze the performance of major technology stocks. 

Developed as an **IEEE Graduation Project**, this application demonstrates advanced data handling, financial analytics, and interactive web application development.

## 🚀 Features
* **Interactive Visualizations:** Dynamic charts and graphs representing historical stock trends and patterns.
* **Financial Analytics:** Deep statistical analysis and performance metrics of tech stocks over time.
* **Modular Architecture:** Clean, maintainable, and scalable codebase separated into logical components.

## 🛠️ Tech Stack
* **Language:** Python
* **Framework:** Streamlit
* **Data Processing & Visualization:** Data handling via robust Python libraries tailored for financial analysis.

## 📂 Project Structure
* `app.py`: The main Streamlit application interface.
* `analytics.py`: Contains the core mathematical models and statistical calculations.
* `plots.py`: Handles all data visualization and chart generation logic.
* `data_loader.py`: Manages data ingestion and preprocessing.
* `tech_stocks.csv`: The historical stock market dataset.
* `requirements.txt`: List of Python dependencies required to run the project.

## 💻 How to Run Locally

1. **Clone the repository:**
```bash
git clone https://github.com/Darwish-V12/Tech-Stocks-Dashboard.git
```

2. **Install the required dependencies:**
```bash
pip install -r requirements.txt
```

3. **Run the Streamlit application:**
```bash
streamlit run app.py
```
